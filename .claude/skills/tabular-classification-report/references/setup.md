# Setup

```bash
pip install -r requirements.txt     # pandas, scikit-learn>=1.3, scipy, matplotlib
brew install tectonic               # or: cargo install tectonic / conda install -c conda-forge tectonic
```

Tectonic downloads the LaTeX packages it needs on first use (network required once).
Tested with Python 3.11, scikit-learn 1.3.0, pandas 2.0.3, scipy 1.11.1, matplotlib 3.7.2.
